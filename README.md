## Demonstrated Skills

- Correlating endpoint logs, SIEM alerts, and network telemetry.
- Reconstructing incident timelines in UTC.
- Creating and validating scheduled SIEM alerts with positive and negative controls.
- Preserving evidence and documenting its provenance.
- Assessing authentication and endpoint activity, including escalation criteria.
- Explaining findings, collection limitations, and lessons learned.

## Scope

These projects are authorized laboratory simulations. Each investigation distinguishes observed evidence from assumptions and documents collection limitations.
